# The Funniest Toaster Error Message

Entry for make.fun's "The Funniest Toaster Error Message" bounty
(`u-eager-stork-81-9647-the-funniest-toaster-error-436406cd`).

`main.py` writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`): the error message a kitchen toaster shows its owner
when something goes wrong — deadpan, apologetic, and quietly dramatic.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

The entry (73 characters, limit 120):

> ERROR: TOASTING CANCELLED. THE BREAD LOOKED AT ME, AND I COULD NOT DO IT.
